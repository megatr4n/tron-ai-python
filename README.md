# Курсовий проєкт: Розробка Гібридного Штучного Інтелекту для гри «Tron»

У даному проєкті реалізовано графічний рушій гри «Tron» за допомогою бібліотеки Pygame та розроблено алгоритм гібридного штучного інтелекту на основі алгоритму Minimax, Нейронної Мережі (MLPRegressor) та пошуку в ширину (BFS).

## 1. Опис предметної області та правила гри
Гра проходить на кібернетичній сітці 16 рядків на 24 колонки. Дві ворожі програми, представлені як Світлові Диски (Блакитний/Cyan та Малиновий/Magenta), пересуваються полем, залишаючи за собою суцільний потік даних (Data Stream). 
Мета гри - змусити алгоритм супротивника врізатися у слід іншої програми або у свій власний код.
- **Замкнута Топологія (Torus Map):** У грі більше немає зовнішніх стін! Якщо гравець виїжджає за правий край екрана, він миттєво з'являється з лівого боку (як у грі Pac-Man). Це перетворює дошку з площини на математичний Торус, що робить алгоритми пошуку ШІ (BFS та Minimax) набагато складнішими і цікавішими.
- **Бонуси (Cores):** Збір енергетичних ядер дає перевагу в очах ШІ (додаткові бали до оцінки позиції).
- **Портали (Quantum Portals):** На полі існують пари порталів. В'їзд в один миттєво переносить гравця до іншого.
Гравець може грати вручну (клавіші зі стрілочками) проти ШІ, або увімкнути режим "Автопілот" (клавіша `A`) для битви двох нейромереж.

## 2. Архітектура програми
Проєкт побудований за модульним принципом з чітким розділенням відповідальності:

```
Tron_Coursework/
├── main.py - точка входу, запуск ігрового циклу Pygame
├── requirements.txt - залежності (pygame-ce, scikit-learn, pandas)
├── README.md - документація проєкту
│
├── game/ - ядро гри (чистий Python без UI та AI)
│   └── state.py - стан арени, розрахунок доступних ходів, обробка порталів та збору бонусів (TronState)
│
├── ai/ - штучний інтелект та машинне навчання
│   ├── minimax.py - алгоритм пошуку Minimax з оцінкою через Neural Network
│   └── ml_model.py - генерація датасету (5000 унікальних партій) та тренування MLPRegressor
│
└── ui/ - графічний інтерфейс
    └── renderer.py - малювання сітки, програм (дисків), порталів, потоків даних та аналітичної HUD-панелі
```

### Як взаємодіють модулі:
- **main.py** керує ігровим циклом (Game Loop) та подіями клавіатури, передаючи стан у **Renderer**.
- **Minimax** взаємодіє з `TronState` для симуляції майбутніх кроків, і викликає `MLPRegressor` для оцінки "якості" майбутніх станів.
- **Game State** не містить жодної логіки відмальовки чи машинного навчання - це виключно математична модель дошки.

## 3. Реалізація алгоритмів штучного інтелекту

### Алгоритм Minimax
Для тактичних рішень (на 4 кроки вперед) використовується класичний Minimax. Він гарантує, що бот ніколи не обере хід, який гарантовано призведе до зіткнення у найближчі секунди, і завжди намагатиметься загнати суперника в глухий кут. Якщо стикаються два безвихідні становища, алгоритм розпізнає нічию (оцінка `0`).

### Налаштування складності (Глибина пошуку)
Глибина прорахунку алгоритму `Minimax` (кількість кроків наперед) налаштовується прямо під час гри від 1 до 5:
- **1-2 кроки:** Легкий рівень. ШІ бачить лише найближчі загрози і приймає рішення майже миттєво.
- **3-4 кроки:** Середній/Складний рівень (за замовчуванням 4). ШІ починає будувати пастки та передбачати комбінації.
- **5 кроків:** Експертний рівень. Глибокий прорахунок, що займає більше процесорного часу, але приймає ідеальні рішення.
Глибину можна змінити клавішами `1`, `2`, `3`, `4`, `5` на клавіатурі. Поточне значення виводиться на Дебаг-панелі.

### Машинне Навчання (Neural Network)
Оскільки прорахувати гру Tron до самого кінця неможливо (занадто велике дерево рішень), на "листових" вузлах дерева Minimax працює **Нейронна Мережа (MLPRegressor)**.
- При першому запуску гра генерує 5000 випадкових ситуацій.
- На цих даних тренується модель `scikit-learn` (Multi-Layer Perceptron), яка вчиться прогнозувати "Перевагу" (TargetScore) на основі ознак (Features).
- **Features:** відстань обох гравців до центру, відстань між ними, та кількість доступних вільних клітинок навколо них.

### Евристика "Flood Fill" (BFS)
Нейромережа добре бачить глобальну картину, але для оцінки реального контролю території додано класичний алгоритм пошуку в ширину (BFS). Він швидко обчислює "площу" доступних клітинок (до 40 кроків) і гарантує, що бот максимізуватиме свій життєвий простір.

### "Творчий шум" (Random Noise)
Щоб уникнути детермінованих (однакових) ігор, до фінальної оцінки ходу додається невеликий коефіцієнт шуму `random.uniform(-15, 15)`. Це дозволяє ШІ обирати різні маршрути на відкритому просторі, імітуючи "живу" поведінку, але шум занадто малий, щоб змусити бота врізатися у стіну (штраф -10000).

## 4. Графічний інтерфейс користувача
Справа на екрані розташована аналітична панель `HUD (Heads-Up Display)`, яка дозволяє "зазирнути під капот" штучному інтелекту:
- **Оцінка Території (BFS):** показує, скільки доступних клітинок бачить кожен бот.
- **Probability Bar (Ймовірність Перемоги):** шкала відсотків, яка візуалізує прогноз Нейромережі (`MLPRegressor`). Вона постійно зміщується залежно від того, чий позиційний статус кращий.
- **Бонуси:** лічильник зібраних енергетичних ядер.

## 5. Інструкція з розгортання та запуску

Вимоги: Python 3.10 або новіший.

1. Відкрити термінал у папці з проєктом:
```bash
cd "шлях_до_папки"
```

2. Створити та активувати віртуальне середовище (рекомендовано):
```bash
python3 -m venv venv
source venv/bin/activate
```
*(Для Windows: `venv\Scripts\activate`)*

3. Встановити бібліотеки:
```bash
pip install -r requirements.txt
```

4. Запустити гру:
```bash
python3 main.py
```
*(При першому запуску гра витратить ~5 секунд на генерацію датасету та тренування нейромережі, після чого автоматично збереже `tron_model.pkl` і запуститься).*
